# Cloud-Resource-Inventory
A Java command-line tool that models common cloud infrastructure resources
(EC2 instances, S3 buckets, RDS databases) using object-oriented principles
like inheritance, polymorphism, interfaces, and abstract classes.

Built as a hands-on companion project while studying for the AWS Cloud
Practitioner certification, each new resource type added to this project
corresponds to a concept covered in AWS coursework.

# Concepts Practiced
- Interfaces and abstract classes
- Inheritance and polymorphism
- Object-oriented design applied to real-world cloud resource modeling

In progress: currently building out core resource classes.
